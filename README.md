# Arcadia Studio — استوديو أركاديا

برنامج ويندوز لإدارة متجر **ARCADIA** (المبني على VIDEOSTORE) لجهاز PS3.

## المزايا
- فتح ملف PKG مباشرة (يفك الحزمة تلقائياً) أو فتح مجلد مستخرج.
- تصفح كل الأقسام والألعاب كشجرة، مع معاينة بشكل واجهة XMB والخلفية.
- تعديل العنوان والوصف بالعربي بشكل طبيعي — البرنامج يحوّل النص تلقائياً للشكل الذي يفهمه XMB.
- تغيير الأيقونة وخلفية القسم بصور PNG من جهازك.
- إضافة لعبة أو قسم جديد مع اختيار القسم من قائمة (القائمة الرئيسية، PS3 › HEN، PS2، ...)، الحذف، وإعادة الترتيب.
- طرق التنزيل: webMAN في الخلفية (موصى به) / متصفح PS3 / متجر PSN.
- بناء ملف PKG جديد جاهز للتثبيت.
- **الإرسال للجهاز مباشرة عبر الشبكة (يتطلب webMAN MOD):**
  - ⚡ **تحديث سريع**: يرسل الملفات المعدّلة فقط إلى `/dev_hdd0/game/VIDESTORE` بدون إعادة تثبيت.
  - 📤 **إرسال PKG**: يرفع الحزمة إلى `/dev_hdd0/packages` ويطلب تثبيتها عبر webMAN.
  - 📡 **إعداد PS3**: إدخال IP الجهاز واختبار اتصال FTP وwebMAN.
- تصدير كتالوج JSON (سيستخدمه تطبيق أركاديا على PS3).

## النشر للجميع (تحديث كل من ثبّت المتجر)
1. سجّل حساباً مجانياً في archive.org وخذ المفاتيح من https://archive.org/account/s3.php
2. في البرنامج: 🔑 إعداد النشر ← اسم عنصر ثابت (مثل `arcadia-ps3-store-cruyfford`) + المفاتيح.
3. اضغط 🌍 نشر للجميع: يبني نسخة جديدة برقم إصدار، ويرفعها إلى `http://archive.org/download/<العنصر>/latest.pkg`.
4. أول مرة فقط: وزّع ملف الحزمة على الناس. بعدها أي تعديل تنشره يوصلهم من داخل المتجر عبر "تحديث أركاديا".

## 🎮 محوّل الألعاب (لكل جهاز تبويب وقسم خاص)
- **PS1**: ملف .cue/.ccd (يدعم الأقراص المتعددة) ← حزمة PKG بصيغة PSone Classic (محرك pop-fe المدمج).
- **PS2**: ملف .iso أو .bin/.cue ← ملف PS2 Classic مشفّر `.BIN.ENC` (منفذ Python لأداة ps2classic، مطابق لها بايت ببايت).
  يتطلب على الجهاز PS2 Classics Placeholder مفعّلاً، ويُشغَّل من webMAN (مجلد `/dev_hdd0/PS2ISO`).
- بعد التحويل: إرسال للجهاز مباشرة، و/أو رفعه على archive.org وإضافته تلقائياً لقسم
  "ألعابي المحوّلة - PS1" أو "ألعابي المحوّلة - PS2" في المتجر.

## ⬇ التنزيل السريع
مدير تنزيلات مدمج يقسم الملف إلى عدة أجزاء تتنزل في نفس الوقت (حتى 16 اتصالاً) مع إيقاف واستئناف،
ويحوّل روابط MediaFire إلى روابط مباشرة. بعد اكتمال التنزيل: زر "إرسال للجهاز" (PKG يُثبَّت، و BIN.ENC يذهب إلى PS2ISO).
تجده في: زر "⬇ تنزيل" تحت المحرر، زر "⬇ تنزيل المحدد" في فحص الروابط، وزر "⬇ التنزيلات" في الشريط العلوي.

## 📦 عارض PKG
يفتح أي حزمة PS3/PSP (Debug أو Retail) بالسحب والإفلات: يعرض الأيقونة والخلفية ومعلومات PARAM.SFO
(الاسم، رقم اللعبة، النوع، الإصدار، الفيرموير المطلوب) وشجرة كل الملفات بأحجامها، مع استخراج الكل أو المحدد،
وإرسال الحزمة للجهاز.
**✏ تعديل الحزمة:** يفكها إلى مجلد، تغيّر الاسم/الأيقونة/الخلفية أو تضيف وتحذف وتستبدل ملفات (أو تعدّل في المجلد مباشرة)،
ثم **🛠 إعادة البناء إلى PKG** — الحزمة الجديدة تُثبَّت على HEN/CFW (حزم Retail تُعاد كحزم Debug). ملفات اللعبة المحمية (EBOOT/EDAT) تبقى مشفّرة برخصتها.

## 🔗 فحص الروابط
يفحص كل روابط التنزيل في المتجر أو أي قسم تختاره من القائمة، مع صورة كل لعبة بجانب اسمها، من الكمبيوتر: ✅ يعمل / ❌ معطل / ⚠️ غير مؤكد، مع حجم الملف.
فلترة المعطلة، فتح ونسخ الرابط، تصدير تقرير CSV، وحذف العناصر المعطلة من المتجر.

## التراخيص
- pop-fe: LGPL-2.1 (مجلد engines/popfe). ps2classic (flatz): GPLv3 — توزيع البرنامج يكون وفق GPLv3.

## التشغيل
**الأسهل:** دبل كليك على `ArcadiaStudio.bat` — أول مرة يجهّز كل شيء تلقائياً (يحتاج Python مثبت) وبعدها يفتح البرنامج مباشرة.
إذا ما فتح البرنامج، شغّل `ArcadiaStudio_debug.bat` ليظهر سبب الخطأ.

أو يدوياً:
```
pip install -r requirements.txt
python run_studio.py
```

## بناء ملف EXE
ارفع المجلد إلى مستودع GitHub، وسيبني GitHub Actions ملف `ArcadiaStudio.exe` تلقائياً (تبويب Actions ← Artifacts).
