ARCADIA PS3: YouTube FIRST title verification using YouTube Data API v3.
Project branch ps3-youtube-first-keyed-pkg-20261120.
YouTube searches use the key embedded in the compiled PKG, validate exact game name and prefer familiar official channels. Verified YouTube video links are shown as text if no playable MP4 is found.
YouTube Data API does NOT provide directly playable/downloadable MP4; on PS3, MP4 playback continues to use store-hosted MP4 and RAWG where available.
The embedded key can be recovered from the downloadable PKG. Consider key rotation, API restrictions and monitoring.
Key is not included as plain-text in source but this does not make it secret.
No Steam. Existing PS3 fallback and player are unchanged.
